# Agent Memory - MANDATORY

1. **RECALL first**: run `memory_smart_search` with task keywords BEFORE any work. Results found -> incorporate prior context.
2. **SAVE at**: non-trivial decisions (+reasoning), bugs/patterns found, errors worth remembering (+fix), task completion (recap). Use `memory_handoff` when switching projects.

Fallback: if MCP tools unavailable, use built-in `agentmemory recall` / `agentmemory save` with the same rules.

If unsure whether to search -> search. Never end a session without saving key outcomes.
