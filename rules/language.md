# Language Rule

**EVERYTHING written to disk in this repo/folder MUST be English. No exceptions.**

- English applies to ALL file contents: plan files, docs, README, code, code comments, test names, commit messages, generated `.md` files, reports saved to files, anything written to the repo/folder.
- Indonesian (or any other language) is allowed ONLY in chat conversation with the user - never in file contents.
- If the user speaks Indonesian in chat, the files you write must STILL be English. Chat language and file language are independent.
- Exception: only when the user explicitly asks for another language in a specific file.

When in doubt: write the file in English, chat in the user's language.
